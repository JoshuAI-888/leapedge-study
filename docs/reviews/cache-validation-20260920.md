## Repair and regression evidence

A deliberately misdirected cache pointer could previously reuse a donor created for a different cutoff: the lookup key represented the requested policy, but the donor itself did not retain that policy for independent validation. A failing behavioural test reproduced one provider call where two were required. Donor records now retain versioned identity, cutoff, normalized primary domains and originating run. Lookup independently validates these fields, donor key, query and time mode. The test now passes and obtains fresh eligible evidence.

Previously stored donors lacking the new identity safely miss cross-run reuse. Their same-run durable responses remain replayable without another paid request. No migration, record deletion or cache TTL expansion is needed.

# VideoConviction dataset: licence, use and attribution

The VideoConviction benchmark harness (`src/server/youtube-intelligence/vc-benchmark.ts`, spec section 4.9) scores our extraction against expert labels from the VideoConviction dataset published by the Georgia Tech FinTech Lab.

- Dataset: https://huggingface.co/datasets/gtfintechlab/VideoConviction
- Paper: Galarnyk, Kejriwal, Shah, Bhardwaj, Watney Meyer, Krishnan, Chava. *VideoConviction: A Multimodal Benchmark for Human Conviction and Stock Market Recommendations.* KDD 2025, Datasets and Benchmarks track.
- Code: https://github.com/gtfintechlab/VideoConviction

## Licence: CC BY-NC 4.0, non-commercial use only

The dataset card states the licence as Creative Commons Attribution-NonCommercial 4.0 (the GitHub repository's `LICENSE.md` says CC BY-NC-SA 4.0). Either way:

- **Non-commercial use only.** Finradar and the YouTube Intelligence lab are a personal, non-commercial project, so evaluation use is permitted. If the project ever becomes commercial, delete `evaluations/vc-benchmark-fixture.json`, keep only the findings (facts are not copyrightable) and either obtain a licence or relabel our own segments.
- **Attribution is required** wherever the data or a derivative of it appears. The attribution text below travels in the fixture header (`attribution` field), in this document and in every `vcBenchmark` report document.
- **ShareAlike** (if the repository licence applies) binds only if a derived dataset is redistributed. The committed fixture is a derived sample, so it ships under the same terms with this document as the change indication: it keeps the first 60 rows of the train split, only the label columns and the segment transcript, and drops media, full-video transcripts, channel statistics and comments.
- **Never product data.** The fixture and benchmark outputs are evaluation inputs and workspace-internal `yi_documents` (kind `vcBenchmark`). They never appear in the product's claims, leaderboard, digests or public share snapshots (spec section 4.11).

## What the fixture contains

`evaluations/vc-benchmark-fixture.json` is generated by `node scripts/vc-benchmark-fixture.mjs [--rows 60]` from the Hugging Face datasets-server rows API (no parquet tooling, no media download). Header fields: `dataset`, `split`, `license`, `attribution`, `source`, `fetchedAt`, `datasetRows`, `columns`, `placeholder` (`true` only if the file was hand-written because the network was unavailable). Each row keeps:

| Field | Dataset column | Note |
|---|---|---|
| `id` | `row_idx` as `train:<n>` | No dataset column is unique per row (`id`, `annotation_id` and `derived_inner_id` identify the annotated video), so the split position is the key. |
| `datasetId`, `videoId`, `start`, `end` | `id`, `video_id`, `start`, `end` | Segment identity and bounds in seconds. |
| `actionSource` | `action_source` | `Title`, `Selected region`, `Introduction`, `Conclusion`; the paper's prompting set is `Selected region`. |
| `expected.isRecPresent` | `is_rec_present` | `Yes` or `No`. The 73 no-rec rows in the split have null labels and an empty segment transcript. |
| `expected.action` | `action` | `Buy`, `Hold`, `Don't buy`, `Sell`, `Short sell`, `Unclear` or null. |
| `expected.convictionScore` | `conviction_score` | 1, 2, 3 or null. |
| `expected.ticker` | `ticker_name` | As published; normalised format-only at scoring time (`NYSE: WMT` becomes `WMT`, `APPL` stays a miss). |
| `transcript` | `segment_transcript` | The expert-retained excerpt the label applies to. |

The first 60 rows are skewed toward `Buy` (53 Buy, 4 Sell, 2 Don't buy, 1 Unclear, no no-rec rows). This is the pilot fixture the plan asked for; a stratified sample or the full 760 rows is one `--rows` argument away and is a decision for the phase-1 gate.

## How labels are compared

`src/features/youtube-intelligence/conviction-mapping.ts` holds the mapping in both directions with a rationale per row (`MAPPING_TABLE`). Dataset labels are translated to our stance (Buy to long, Sell and Short sell to short, Hold to hold, Don't buy to avoid, Unclear to watch as the weakest stance), and both sides are projected onto a coarse action space (buy, sell, hold, none) for the confusion matrix. Conviction scores 1, 2, 3 map to low, medium, high; our `unspecified` has no score and never earns agreement. Where a translation is lossy the weaker reading is chosen, so the benchmark can under-count our precision but never inflate it.

Run the harness offline with `node --experimental-strip-types scripts/vc-benchmark.ts --offline`; score a real extraction with `--extraction <file>`.
